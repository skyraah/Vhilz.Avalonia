## Classes 与选择器契约

- 无新增库 Classes。
- 样式仅作用于本卡 ControlTheme 的 `^`、命名自有模板部件和官方必要局部子控件；没有全局 Button / TextBlock 修补。
- 选中保持中性 Selection/OnSelection；Tabs 选中为 Surface/Text。悬停排除禁用，选择与悬停组合不清除选中信息；禁用以 Opacity.Disabled 保留选中结果。键盘焦点独立描边。
- 输入控件（本卡涉及时）错误保留 Danger 边框；独立 FocusVisual 外环由真实 `:focus-within` 产生并排除禁用，可与错误同时存在。Calendar 用官方 dayfocused / btnfocused 代替 Button 的键盘焦点伪类。
- 宿主公开 Background / Foreground / BorderBrush / BorderThickness / CornerRadius / Padding / ContentTemplate 通过 TemplateBinding 传入部件；局部几何直接 DynamicResource。模板不改键盘或选择算法。TreeView 的节点悬停例外见范围说明。
