## 契约与选择器

HyperlinkButton 保留 NavigateUri / visited / AccessKey；DropDownButton 保留原生 Flyout 触发。SplitButton 保留 PART_PrimaryButton、PART_SecondaryButton、主按钮 Command / CommandParameter、TabStop 与焦点分工。ToggleSplitButton 的 StyleKeyOverride 为 SplitButton，checked / flyout-open 由上游产生；内部 Tag 投射沿用原模板生产者。

无新增 class；Split 内部 Tag=checked / flyout-open / checked-flyout-open 仅自有子 Button 消费。Tag 是上游模板内部状态，不能由应用当作公开变体。内部子按钮背景通过 Presenter 状态处理，因为 TemplateBinding 的子按钮局部值需保留；宿主尺寸/圆角/边界仍绑定。
