## 契约与选择器

PART_HeaderPresenter / PART_ContentPresenter 保留 Header、HeaderTemplate、Content、ContentTemplate、内容对齐和 Padding。官方 BorderGapMaskConverter 保留标题边界缺口，背景单独 Border 避免同时被裁去。

无 class，纯展示容器没有适用 hover / pressed / selected；内部控件保留自身状态。Header/Content 属于消费者内容，不使用跨组件选择器。
