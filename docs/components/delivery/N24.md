## 契约与选择器

管理器 PART_Items 使用原生 ReversibleStackPanel 与 INotification / String DataTemplates；六个 Position 伪类保留方向与顺序。NotificationCard.CloseOnClick、IsClosing、IsClosed 和 NotificationClosed 保留。关闭完成沿用上游非视觉 IsClosed Animation，1 ms 延后，避免 CloseAll 枚举时同步修改集合；没有入场、位移、缩放动画。

没有新增 class；关闭 Button 消费内部命名主题 Vhilz.Button.Subtle.Theme。图标样式仅触及本卡 PART_TypeIcon；错误边框 Danger，背景保持 Popup。管理器只通过原生位置伪类设置 PART_Items 对齐/ReverseOrder。
