# F01 — 原生外观共享资源

主工作区串行接入，保留既有表面、窗口与按钮资源值。新增资源由实际原生主题消费，
不新增控件公共属性，不引入依赖，不建立未使用尺寸集合。

| 键族 | 类型 | 用途 / 默认候选 |
| --- | --- | --- |
| Color / Brush.Primary、PrimaryHover、PrimaryPressed、OnPrimary | Color / SolidColorBrush | 选中标记、轨道填充与逆色提示；明色近黑、暗色近白，对应相反前景 |
| Color / Brush.Input、Popup | 同上 | 输入与浮层表面；明色白、暗色 #202023 |
| Color / Brush.Selection、OnSelection | 同上 | 列表、菜单及文本选择；明色 #E4E4E7、暗色 #3F3F46 |
| Color / Brush.Danger、Focus | 同上 | 校验错误与独立焦点；主题对应颜色见 Light/Dark |
| Height.Control | Double | 32 DIP，沿用现有按钮密度 |
| FontSize.Body、Caption | Double | 14 / 12 DIP |
| FontFamily.Body | FontFamily | Default，不为库新增字体依赖 |
| Thickness.Border | Thickness | 1 DIP |
| Padding.Control、Item、Popup | Thickness | 12,6 / 8,6 / 8 |
| Padding.TabStrip、TabContent | Thickness | 3 / 0,8 |
| Radius.Full | CornerRadius | 999，圆形轨道/标记；Small 保留 5 |
| Shadow.Popup | BoxShadows | 0 4 16 0，明色 #20000000、暗色 #40000000 |

Color 与画笔分别可覆盖，画笔动态引用语义颜色。跨主题值位于 Tokens，差异位于明暗字典，ResourceKeys 同步。
控件独占几何和尺寸留在其字典，并由相应交付包登记。统一命名和覆盖方式见资源规范。

所有新增视觉参数仍待用户观察，不声称已确认全局视觉档位。最终明暗键/类型一致性和动态覆盖结果见 [本轮交付](native-appearance.md)。
