# N01 — Button 与 RepeatButton

接续 F00 的未提交 Button 基线，保留 PART_ContentPresenter、访问键、命令、默认/取消与可选缩放契约。
按钮 Padding、MinHeight、BorderThickness、FontSize 改为共享动态资源；悬停显式排除 pressed，避免同属性状态竞争。
没有新增按钮变体或动效。RepeatButton 基于 Vhilz.Button.Theme，沿用原生 Delay/Interval 和按住触发。

入口按 `avares://Vhilz.Avalonia/Themes/Controls/Button.axaml` → `RepeatButton.axaml` 加载，均为 ResourceDictionary。
命名主题 `Vhilz.Button.Theme` / `Vhilz.RepeatButton.Theme` 与对应类型键入口共存。
选择器只命中当前 Button 主主题宿主和两个自有 PART；无新增 Classes。现有 ButtonMotion 是唯一缩放配置来源。

Demo：`Vhilz.Avalonia.Demo.Components.N01.N01Sample`，包含普通/访问键/长文本/默认/取消/禁用/不可执行命令，
点击和 RepeatButton 更新计数。明暗由目录窗口切换。

共享申请：Padding.Control、Height.Control、Thickness.Border、FontSize.Body，已由 F01 接入。
现有 ButtonTests 沿用，最终构建/过滤回归见 [本轮交付](native-appearance.md)。
人工观察按住连发、焦点轮廓、明暗对比及现有缩放；Linux/macOS 和真实平台效果未验证。
