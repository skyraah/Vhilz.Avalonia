## 颜色反馈配置（2026-10-13，视觉待验收）

接续已有未提交的下沉实现，主 agent 串行修改 ButtonMotion.cs、Button.axaml、ButtonTests.cs、N01Sample.axaml、README.md 与本记录，新增内部 ButtonContentPresenter.cs。未新增依赖、资源键或 Classes，也未改变主题入口。

- `ButtonMotion.IsPressStyleEnabled` 默认 true，仅控制按下背景色。关闭后指针按住保留 hover 色，键盘按住且无 hover/flyout 时保持常态色；不影响 Scale/Sink、Click 或 Command。
- `ButtonMotion.IsColorAnimationEnabled` 默认 true，控制背景颜色过渡，hover、press 和退出状态共用；关闭时移除颜色 Transition，形变动画继续工作。
- `ButtonMotion.ColorAnimationDuration` 为非负 TimeSpan，主题通过 DynamicResource 使用现有 `Vhilz.Duration.Fast`（80ms）。允许局部设置、样式 Setter、绑定及运行时更新，零时长立即切换。

Transition 本身没有模板宿主，不能直接使用 TemplatedParent 绑定。内部 ButtonContentPresenter 继承 ContentPresenter，保留 `PART_ContentPresenter`、原生内容/访问键契约，由模板传入配置，持有每个实例独立的颜色与形变 Transition。选择器只命中当前主题宿主和自有部件；按下色由开关与原生 pressed 共同决定，disabled 排除交互染色。RepeatButton 继承同一主题，因此适用相同配置。

Demo N01 增加关闭按下色但保留下沉、立即切色、Slow Token 颜色过渡和禁用对比；点击仍更新计数，沿用目录明暗切换与 Tab/空格焦点检查。

验证：`dotnet build Vhilz.Avalonia.sln --artifacts-path artifacts/agent` 通过，0 警告、0 错误；ButtonTests 与 N01Tests 聚焦回归共 28 项通过。覆盖明暗下关闭按下色、按住时切换开关、鼠标/键盘点击、独立下沉效果、动态时长资源、按钮实例隔离、颜色动画开关、零/负时长及既有按钮契约。
Headless 仅确认结构、参数与状态行为；渐变流畅度、明暗对比、焦点和实际平台效果待用户通过 Demo 观察，Linux/macOS 未验证。
