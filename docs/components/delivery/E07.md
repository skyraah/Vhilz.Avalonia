## 契约与选择器

保留 PART_OverflowButton、PART_PrimaryCommands、PART_OverflowPopup、PART_OverflowPresenter 及 ContentPresenter。VisiblePrimaryCommands / OverflowItems、IsOpen 双向绑定与原生键盘 Cycle、轻关闭均保留。按钮的 Label / Icon、IsCompact、LabelPosition、IsInOverflow 由上游布局处理。

无 class。配置阶段先处理 Compact / Right / Overflow 布局，选中默认面 ControlPressed，hover ControlHover（排除 pressed/disabled），pressed ControlPressed，disabled 整体透明度；focus-visible 使用自有 BorderBrush，不穿越 N01 Button 私有模板。
