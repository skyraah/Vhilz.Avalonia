阶段：P1；预估风险：高。状态和负责人只在 [领取记录](../claims.md#n09) 维护。先读 [执行约定](../work-contract.md)，不要修改其他卡的文件。

同一任务拥有单行、多行输入及校验视觉；MaskedTextBox 沿用上游 TextBox 样式键。定义占位、只读、选择、错误和焦点状态。

## Demo 与可观察结果

单行、多行、密码、只读、禁用、掩码、错误到恢复、长输入、中文输入；明暗运行时切换。

所有适用场景同时具备明暗主题；悬停、按下/选中、禁用和键盘焦点使用真实操作观察。未适用状态写“不适用”及原因，不人为给纯展示控件制造交互。默认外观、快速状态切换和应用覆盖沿用执行约定。
