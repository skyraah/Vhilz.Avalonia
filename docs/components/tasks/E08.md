shadcn 目录对应：不直接对应 shadcn 目录项；属于原生支持依赖或 Avalonia 补齐项。

- 通用前置：[F00](F00.md) 基线/Demo 协议可用；[F01](F01.md) 首轮资源契约可用。
- 组件硬依赖：无组件硬依赖。依赖已集成且入口稳定后可编码；最终验收使用共同基线。
- 决策或交接：无额外决策；先核对当前版本的原生 API 与模板，再选择本任务测试强度。
- 按当前项目依赖版本核对 Avalonia 官方源码与主题；不能把本文列举的属性视为穷尽清单。
