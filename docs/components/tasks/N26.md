# N26 — TableView 与表格场景

阶段：P2；预估风险：高。状态和负责人只在 [领取记录](../claims.md#n26) 维护。先读 [执行约定](../work-contract.md)，不要修改其他卡的文件。

## 目标与实现边界

优先评估当前 Avalonia 核心 TableView 后实现原生主题。第一里程碑是只读数据表格，第二里程碑才覆盖经核实的原生编辑、排序、选择等能力。

按实际 TableView 源码登记属性和部件；列宽、表头、行选择、单元格模板、滚动/虚拟化保持上游契约，不把 DataGrid 的属性直接套过来。

## Demo 与可观察结果

空/少量/长列表、长单元格、横纵滚动、列调整及已实现的编辑/排序；静态 Table 与 Data Table 差异在交付中说明。

所有适用场景同时具备明暗主题；悬停、按下/选中、禁用和键盘焦点使用真实操作观察。未适用状态写“不适用”及原因，不人为给纯展示控件制造交互。默认外观、快速状态切换和应用覆盖沿用执行约定。
