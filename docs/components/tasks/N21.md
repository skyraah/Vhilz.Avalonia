## 必须保留或先确定的契约

SelectedDate/SelectedDates、显示年月、SelectionMode、BlackoutDates、文化/首日和键盘移动。

## Demo 与可观察结果

单选/区间、多范围按上游、跨月、禁选日期、文化差异、明暗焦点可辨认。

所有适用场景同时具备明暗主题；悬停、按下/选中、禁用和键盘焦点使用真实操作观察。未适用状态写“不适用”及原因，不人为给纯展示控件制造交互。默认外观、快速状态切换和应用覆盖沿用执行约定。
