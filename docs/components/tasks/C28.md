## 必须保留或先确定的契约

用户主动滚离底部后停止强制跟随、历史插入不跳动、定位不存在项和取消清晰；不靠固定延时猜布局。

## Demo 与可观察结果

流式追加、手动滚离/回底部、插入历史、跳转消息、改变窗口宽度。

所有适用场景同时具备明暗主题；悬停、按下/选中、禁用和键盘焦点使用真实操作观察。未适用状态写“不适用”及原因，不人为给纯展示控件制造交互。默认外观、快速状态切换和应用覆盖沿用执行约定。
