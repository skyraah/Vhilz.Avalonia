# N15 — ComboBox 与选择下拉

阶段：P2；预估风险：高。状态和负责人只在 [领取记录](../claims.md#n15) 维护。先读 [执行约定](../work-contract.md)，不要修改其他卡的文件。

## 目标与实现边界

为原生 ComboBox 及其项定义关闭态、打开态、占位、空列表和校验；Native Select 只登记桌面用途对应，不制造浏览器原生行为。

shadcn
目录对应：[select](https://ui.shadcn.com/docs/components/base/select)、[native-select](https://ui.shadcn.com/docs/components/base/native-select)
