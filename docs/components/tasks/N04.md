## 目标与实现边界

为选中、未选中及可选三态定义克制的按钮视觉；共享表面 Token，独立拥有 ToggleButton 模板。

shadcn 目录对应：[toggle](https://ui.shadcn.com/docs/components/base/toggle)

- 决策或交接：无额外决策；领取后核对基线与测试强度。
