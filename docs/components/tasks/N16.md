所有适用场景同时具备明暗主题；悬停、按下/选中、禁用和键盘焦点使用真实操作观察。未适用状态写“不适用”及原因，不人为给纯展示控件制造交互。默认外观、快速状态切换和应用覆盖沿用执行约定。
